# Egon

Discord bot that plans and implements Godot game features with Cursor agents.

## Invite

You need **Manage Server** on the target Discord server.

[Add Egon to a server](https://discord.com/oauth2/authorize?client_id=1422897079751147642&permissions=2815078332484672&integration_type=0&scope=bot+applications.commands)

After the bot joins, set `DISCORD_GUILD_ID` and `DISCORD_CHANNEL_ID` and restart it. Slash commands only work in that channel.
